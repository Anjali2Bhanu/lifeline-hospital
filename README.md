A modern, responsive, multi-speciality hospital website built with HTML5, Tailwind CSS, and Vanilla JavaScript.

## Key Features
1. **24/7 Emergency Header Bar:** Quick access to hotline numbers, OPD hours, and emergency care status.
2. **Hero Section with Quick OPD Booking:** Instant booking card directly above the fold.
3. **Specialities & Medical Departments:** Cardiology, Pediatrics, Orthopedics, Neurology, General Medicine, and Maternity.
4. **Specialist Doctors Directory:** Profiles with qualifications, experience, and consultation schedule.
5. **Interactive Online Appointment Booking:**
   - Full booking form with validation.
   - Dynamic appointment reference ID generator (e.g. `LLH-XXXXXX`).
   - Confirmation popup modal with patient booking details.
   - Saves appointments locally via browser `localStorage`.
6. **Modern Facilities Showcase:** ICU, computerized diagnostic labs, and mobile ambulances.
7. **Contact & Inquiry Section:** Direct email and phone links, working hours, and inquiry form.
8. **Mobile-first & Fully Responsive:** Clean layout across mobile phones, tablets, laptops, and desktop screens.
